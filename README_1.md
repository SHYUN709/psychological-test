# 나의 마음 지도

WPI(황상민)의 10개 축 개념을 빌린 50문항 자기이해 검사. 정식 WPI 검사가 아니며, 문항과 해석은 새로 작성했다.

- 자기평가 5축: 리얼리스트 · 로맨티스트 · 휴머니스트 · 아이디얼리스트 · 에이전트
- 타인평가 5축: 릴레이션 · 트러스트 · 매뉴얼 · 셀프 · 컬처
- 결과: 오각형 차트 2장 + 프로파일 해석 + 다른 AI 채팅에서 이어 쓸 수 있는 프롬프트 복사
